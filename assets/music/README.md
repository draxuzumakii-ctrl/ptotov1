A short original synthesized demo loop is included as `room-tone-demo.wav` so you can test playback. It is deliberately labeled as a placeholder and should be replaced before launch. Add your own audio files here, then list them in `data/playlist.json` with `title`, `artist`, `cover` (optional), and `src` fields. The player never autoplays. Prefer compressed audio such as MP3 or AAC for production.
